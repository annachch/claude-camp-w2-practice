# 学员花名册管理器

一个适合 Python 初学者的命令行项目，使用字典存储学员信息，支持添加、查询和删除操作。

## 功能

- **添加学员**：记录姓名、邮箱和加入日期，不允许姓名重复。
- **查询学员**：输入完整姓名，查看学员信息。
- **删除学员**：根据姓名删除已有记录。
- **输入提示**：姓名、邮箱或日期为空时给出提示；菜单选择无效时允许重新输入。
- **退出程序**：输入 `0` 正常退出，也可通过 `Ctrl+C` 中断程序。

## 运行环境

- Python 3
- 无需安装第三方库

## 使用方法

下载项目后，在终端中进入 `students.py` 所在目录，运行：

```bash
python students.py
```

如果你的系统使用 `python3` 命令，请运行：

```bash
python3 students.py
```

根据菜单输入对应编号：

```text
请输入所需要的操作编号
1：添加学生
2：查询学生
3：删除学生
0：退出
```

## 操作示例

添加学员：

```text
请选择操作：1
请输入学员姓名：张三
请输入学员邮箱：zhangsan@example.com
请输入加入时间 YYYY-MM-DD：2026-10-22
添加成功，Welcome 张三！
```

查询学员：

```text
请选择操作：2
请输入要查询的姓名：张三
姓名：张三
邮箱：zhangsan@example.com
加入日期：2026-10-22
```

## 数据结构

程序使用嵌套字典保存信息，以姓名作为唯一标识：

```python
students = {
    "张三": {
        "姓名": "张三",
        "邮箱": "zhangsan@example.com",
        "加入日期": "2026-10-22",
    }
}
```

## 当前限制

- 数据仅保存在内存中，退出程序后会清空。
- 不支持同名学员。
- 查询和删除需要输入完整且匹配的姓名。
- 邮箱和加入日期仅检查是否为空，尚未验证格式或日期是否真实。
